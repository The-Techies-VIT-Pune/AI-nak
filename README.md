# AI-nak



AI-nak is a research prototype for regime-aware, multimodal

market intelligence and portfolio allocation.



## Vision



AI-nak combines:



1. Dynamic Market Graph Network (DMGN)

2. Multi-Channel Hawkes Event Filter

3. Variational Market State Encoder (VMSE)

4. Tri-Modal Fusion Transformer (TMFT)

5. Regime-Gated Meta-Ensemble

6. Downside-Aware Reinforcement Learning

7. Generative Explainability Engine
